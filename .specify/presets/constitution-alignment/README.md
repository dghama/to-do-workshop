# Constitution-Aligned Engineering preset

This reusable preset composes with standard Spec Kit commands and templates. It
asks the workflow to inspect the consuming repository and its Constitution
instead of assuming a particular language, architecture, test runner, or
deployment setup.

Install from the repository root:

```powershell
specify preset add --dev .\presets\constitution-alignment
```

The preset extends specification and plan templates with repository-aware
quality criteria, and wraps the tasks template with a verification policy.
Behavior, contract, configuration, and data changes require verification
appropriate to their risk; documentation-only changes use relevant
documentation checks without meaningless runtime tests. UI accessibility
guidance applies only to UI changes, with WCAG 2.2 AA as the default target.
TDD is not imposed unless the project Constitution or feature requires it.

## Source and generated artifacts

Maintain all preset-owned behavior in this directory:

| Preset source         | Installed/resolved result                            |
| --------------------- | ---------------------------------------------------- |
| `commands/specify.md` | Composed `speckit.specify` command and Copilot skill |
| `commands/plan.md`    | Composed `speckit.plan` command and Copilot skill    |
| `commands/tasks.md`   | Composed `speckit.tasks` command and Copilot skill   |
| `templates/spec.md`   | Appended to the resolved `spec-template`             |
| `templates/plan.md`   | Appended to the resolved `plan-template`             |
| `templates/tasks.md`  | Wrapped around the resolved `tasks-template`         |

The installed copy under `.specify\presets\constitution-alignment` and its
composed command/skill outputs are generated by Specify; do not edit them
directly. `resolve-template.ps1` composes template sources when a command
requests them. Project-level template overrides intentionally retain their
higher precedence. A higher-priority replacement template can suppress the
appended specification layer; the command still calls for relevant quality
and risk considerations in the replacement's applicable sections.

After changing this source, synchronize the installed copy from the repository
root:

```powershell
specify preset update constitution-alignment --dev .\presets\constitution-alignment
```

`preset update` removes and reinstalls the preset. Keep local customizations in
this source, not in the installed copy, and review generated outputs after
updating. Consuming repositories install the preset from their trusted source
and run the same update command against that source when adopting changes.

The existing Jira branching behavior remains in the separate
`jira-branching` preset and can be installed alongside this preset.
